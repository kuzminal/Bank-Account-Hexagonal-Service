# 0003. Публикация доменных событий в Kafka

- **Статус:** Accepted
- **Дата:** 2025-09-23

## Контекст

Другие системы должны узнавать о создании счёта, пополнении и снятии средств
без синхронной связанности с этим сервисом. Рассматривались синхронные REST-вызовы,
outbox-таблица и асинхронный брокер сообщений.

## Решение

Публикуем доменные события (`AccountCreatedEvent`, `AccountDepositedEvent`,
`AccountWithdrawnEvent`) в топик Kafka `bank-account-events` через выходной порт
`BankAccountNotificationPort`. Адаптер `KafkaBankAccountNotifier` отправляет события,
а подписчики читают топик независимо.

## Последствия

**Плюсы:**
- развязка с потребителями — можно добавлять новых подписчиков без правок сервиса;
- возможность replay событий и горизонтального масштабирования;
- асинхронность — операция со счётом не блокируется медленным потребителем.

**Минусы:**
- нужна схема и версионирование событий (планируется ввести event-контракты);
- текущая схема «dual-write» (запись в БД + отправка в Kafka) не гарантирует
  согласованность между ними — см. ADR-0004.
